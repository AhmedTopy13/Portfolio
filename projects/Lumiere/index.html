Lumière

نظام إدارة الأتيليهات ومراكز التجميل الشامل. حل متكامل يجمع بين إدارة الحجوزات، المبيعات، ومراقبة المخزون.

تحميل البرنامج (v1.3)
Version 1.3 (الأحدث)

الاحترافية والرقابة الكاملة

  • تقرير الربحية الشامل: احتساب صافي الأرباح (الإيرادات - المصروفات) لفترة محددة أو للنشاط بالكامل.
  • المخططات الزمنية (Gantt Chart): (تجريبي) عرض مرئي لفترات حجز الفساتين لتسهيل التنسيق.
  • نظام الطباعة: إصدار إيصالات الحجز بمقاسات مختلفة.
  • الملاحظات التشاركية: مساحة عمل مشتركة لتدوين ومشاركة الملاحظات بين فريق العمل.
  • سجل العمليات (Audit Logs): تتبع دقيق لكل عمليات الإضافة، التعديل، والحذف لضمان الأمان والشفافية.
  • نظام منع التعارض: تحذير ذكي عند محاولة حجز فستان في فترة مشغولة.
  • فترات الأمان (Buffer Time): إضافة تلقائية لفترة 5 أيام قبل الحجز (للتجهيز) و5 أيام بعده (للاسترداد والتنظيف).
  • تحسينات الأداء: اختصارات لوحة مفاتيح وتسريع العمليات.
Version 1.2

التوسع في التفاصيل والماليات

  • تصنيف الفساتين المتقدم: حفظ الفساتين بالاسم والصورة للتوثيق.
  • المعاينة السريعة: ميزة Popup تعرض صورة الفستان عند الوقوف على اسمه في القائمة لمدة 3 ثوانٍ.
  • الإدارة المالية الموسعة: تسجيل المصروفات والإيرادات العامة (خارج نطاق الحجوزات).
  • دقة حالات الحجز:
    - الفساتين: (محجوز - خرج للعميل - تم الاسترداد)
    - الميكاب: (محجوز - تم التنفيذ)
Version 1.0

البنية التحتية والأساسيات

  • إدارة الحجوزات: شاشات مخصصة لإيجار الفساتين وحجز جلسات الميكاب.
  • إدارة المستخدمين والبائعين: نظام صلاحيات متكامل.
  • التقارير الأساسية: فلترة الحجوزات بالتاريخ، الفترة، أو البائع.
  • الأمان: نظام النسخ الاحتياطي وسلة المهملات لاسترجاع البيانات المحذوفة.
  • الداشبورد المالي (Overview): ملخص لقيم الحجوزات، المبالغ المستلمة، المتبقية، والمتأخرات.
  • الأجندة اليومية (Today's Agenda): شاشة جانبية ذكية ترتب المهام اليومية (تسليم فستان، استلام فستان، جلسة ميكاب) زمنياً لضمان سير العمل بدقة.
