Inventory System 1.0

نظام محاسبي متكامل مبني بالكامل داخل بيئة Excel باستخدام VBA. يجمع بين سهولة استخدام الإكسيل وقوة البرمجة المخصصة.

تحميل الملف (xlsm)

مميزات الإصدار 1.0

البحث الذكي (F3)

ميزة قوية تتيح لك الضغط على F3 في أي خانة (مثل العميل أو الصنف) لفتح نافذة بحث منبثقة.
عند اختيار العنصر، يقوم النظام تلقائياً بملء الكود، الاسم، والسعر، وباقي البيانات المرتبطة.

الإدارة المالية

إدارة كاملة للخزينة وتسجيل المعاملات المالية (Transactions).
متابعة أرصدة العملاء والموردين بشكل لحظي من شاشات الإدخال.

التحليل والتقارير

شاشات Overview مخصصة للمشتريات والمبيعات مع إمكانيات فلترة متقدمة للبيانات لتحليل الأداء واتخاذ القرارات.

واجهة تفاعلية (Dark Mode)

تصميم متوافق تماماً مع ثيمات Excel الملونة، مع اعتماد الوضع الليلي (Dark Mode) كواجهة أساسية مريحة للعين.
